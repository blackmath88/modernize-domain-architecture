# Provider Influence

## Precise claim

**Hypothesis:** GitHub Copilot Modernize combines portable application-modernization knowledge with an opinionated Azure-target modernization path.

This is not equivalent to saying that Modernize is merely an Azure funnel. Provider target is architecturally relevant because it can affect identity, messaging, secrets, compute, databases, networking, observability, and infrastructure before deployment execution.

## Product value after separation

**Inferred candidates for durable product value:**

- provider expertise;
- GitHub, IDE, Copilot, and cloud integration;
- orchestration quality;
- validation, evaluation, retry, and operational reliability;
- enterprise UX, trust, and governance;
- distribution;
- accumulated operational migration learning.

**Hypothesis:** language facts, framework rules, compatibility constraints, known transformations, and validators are more portable and may support open or community-maintained packages.

The seven-run experiment in `EXPERIMENT_PLAN.md` exists to test this boundary.
