# Structured Research Model

These JSON documents are the machine-facing interface to the same model described in the canonical root Markdown.

- `thesis.json`: question, current thesis, alternatives, and falsification criteria
- `architecture.json`: components, layers, flows, boundaries, and open questions
- `glossary.json`: normalized terminology
- `claims.json`: labeled claims with source and confidence
- `experiments.json`: seven unexecuted experiment records
- `provenance.json`: source catalog and provenance field contract

JSON `null` and empty arrays are intentional when evidence has not been collected. Do not replace them with inferred results.
