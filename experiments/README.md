# Experiments

The primary experiment compares one unchanged application under seven intents. Follow the root `EXPERIMENT_PLAN.md` and use `runbooks/RUN_TEMPLATE.md` for every run.

Raw outputs belong in `evidence/runs/<experiment-id>/`. Interpretation belongs in canonical documentation and structured claim records. Never edit raw outputs to make comparisons easier; create derived summaries separately and retain provenance.

Run `./experiments/scripts/validate-repository.sh` before committing.
